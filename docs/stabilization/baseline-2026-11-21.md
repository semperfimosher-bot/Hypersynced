## Change safety rules

1. Do not refactor player restoration, seek/progress handling, queue transitions, or offline-download ownership without a specific reproduction and regression coverage.
2. One root-cause fix per change. Avoid bundling unrelated fixes or performance tweaks.
3. Run the narrow tests first, then the relevant full suite(s), and verify the commit's CI before declaring it complete.
4. A deployment is not considered verified until the deploy workflow and health check complete successfully.
5. No production secrets, account settings, or infrastructure changes are to be made without explicit approval.

### Critical user journey regression checklist

- Playback: play/pause/resume, seek, previous/next, natural track end, shuffle/repeat, queue.
- Restore: refresh while paused and playing; progress reflects saved DB position; continue/skip after restore.
- Offline: download completes; downloaded badge survives refresh/navigation/restart; airplane/offline playback; explicit remove; Liked Songs and playlist pins remain independent.
- Library: add/remove song or playlist updates UI immediately; refresh and cross-device state reconcile.
- Search: songs/artists/albums/playlist results; playlist opens and song list appears immediately; search clear/retry.
- Recently Played: accurate item order; immediate UI update; reload and device reconciliation.
- Account/PWA: login/logout/session refresh; install/reopen; offline shell; reconnect.

## Phase 2 — Bug backlog and targeted fixes

- [ ] Each bug has a short title, exact steps, expected vs actual, frequency, and severity.
- [ ] Add a regression test where practical before changing implementation.
- [ ] Fix only confirmed defects; don't guess at the cause.
- [ ] Verify related journeys after each fix.

Severity guide:
- Critical: data loss, auth/security issue, app unusable, or broad playback/offline failure.
- High: important core flow broken for many users or consistently.
- Medium: limited reproducible functional issue with a workaround.
- Low: cosmetic or minor intermittent issue.
